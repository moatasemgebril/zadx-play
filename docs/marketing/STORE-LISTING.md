Zad X Play — Play • Learn • Shine

A family app that helps you shape your child's screen time around Islamic habits: games unlock after prayer and tasks, the adhan pauses play, and prayer times, adhan and the Holy Quran are built in.

## 6. Compliance checklist

### Google Play — Families policy / target audience
- [ ] **Target audience decision (owner/legal):** the child uses the device-side screens, so the audience
      includes under-13s → Families policy applies (mixed audience). Data safety + Families declaration must
      match the privacy policy (anonymous auth, Firestore sync, FCM tokens if push ships).
- [ ] Listing addresses parents only; no calls to action aimed at children.
- [ ] No ads SDKs, no analytics SDKs (pubspec 2026-11-21: none). Firebase Auth/Firestore/Functions are
      Google services, not ad/analytics: they still go in Data safety.
- [ ] `google_fonts` fetches fonts from Google at runtime (IP exposure, breaks offline). Ask engineering to
      bundle fonts before claiming offline/privacy [A4][A7].
- [ ] Accessibility API + Device Admin: Permissions Declaration, prominent disclosure, and the listing line
      "Zad X can lock all apps … Phone and emergency calls are never locked" (included above, per
      STORE_CHECKLIST). Re-check current Accessibility + Families wording for apps whose audience includes
      children before submission.
- [ ] Metadata policy: no "free/no ads/best/#1" in title, icon or developer name (they appear only in the
      description/promo text). No keyword stuffing, no unattributed testimonials, no trademarks.
- [ ] Do not claim "Teacher Approved" or any badge.

### Apple — guideline 1.3 (Kids Category) and related, as relevant to listing text
- [ ] Category: Lifestyle or Education (parent is the purchaser/configurer). If we ever pick Kids
      Category: no third-party analytics/ads, and links out, purchases and other distractions behind a

- [ ] 5.1.4: kids' data rules apply regardless of category; App Privacy labels must match the description.
- [ ] 3.1.2: subscription disclosures + Terms/Privacy links (included).
- [ ] Family Controls Distribution entitlement approved before any listing shows the lock.
- [ ] Age rating questionnaire consistent with no ads, no UGC, no unrestricted web.
