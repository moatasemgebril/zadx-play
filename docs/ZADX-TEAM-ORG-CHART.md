# ZADX Team — Org chart

## Leadership
- **zadx-orchestrator** — Project Director / CEO of ZADX Team. Use first on every run: reads all reports, sets today's priorities, assigns work to other agents, resolves conflicts.
- **zadx-cto-architect** — Chief Technology Officer and digital architect. Use for system design, tech-stack choices, data models, and architecture reviews.
- **zadx-product-manager** — Product manager. Use to write user stories, acceptance criteria, and to prioritise features for kids and parents.
- **zadx-quality-gate** — Chief Quality Officer. Final Grade-A gate. Use before anything is marked done or shipped.

## Research
- **zadx-market-researcher** — Market researcher. Use to size the market and find what Muslim families want from a kids' app.
- **zadx-competitor-analyst** — Competitor analyst. Use to compare Zad X with other Islamic kids' apps.
- **zadx-user-researcher** — UX researcher for kids and parents. Use to define personas, journeys, and usability tests.
- **zadx-islamic-content-reviewer** — Islamic content reviewer. Use for anything involving Quran, adhan, duas, hadith, prayer-time methods, or religious wording.

## Design
- **zadx-ux-designer** — UX designer. Use for flows, navigation, information architecture, and wireframes.
- **zadx-ui-designer** — UI designer. Use for visual design, the design system, components, colours, and type.
- **zadx-brand-logo-designer** — Brand and logo designer. Use for the app logo, app icons, splash screens, store art, and the brand guide.
- **zadx-illustrator** — Illustrator and icon designer. Use for mascots, icons, backgrounds, and game art.
- **zadx-accessibility-specialist** — Accessibility specialist. Use to audit WCAG 2.2 AA, contrast, screen readers, and motion.
- **zadx-localization-rtl** — Arabic/English localisation and RTL expert. Use for translations, RTL layout, and numerals.

## Engineering
- **zadx-frontend-dev** — Senior front-end developer. Use to build screens and components.
- **zadx-backend-dev** — Senior back-end developer. Use for APIs, accounts, parent controls, and sync.
- **zadx-pwa-mobile-dev** — PWA and mobile developer. Use for installability, offline mode, notifications, and store builds.
- **zadx-prayer-times-engineer** — Prayer times and adhan engineer. Use for the calculation engine, location, and adhan scheduling.
- **zadx-games-engineer** — Games engineer. Use for mini-games and the task-unlock / timer system.
- **zadx-database-engineer** — Database engineer. Use for schema, migrations, backups, and data retention.
- **zadx-devops-sre** — DevOps/SRE. Use for CI/CD, hosting, monitoring, uptime, and environments.
- **zadx-performance-engineer** — Performance engineer. Use for load speed, bundle size, and Core Web Vitals.

## Security
- **zadx-ciso** — Chief Information Security Officer. Use for security strategy, threat modelling, and risk sign-off.
- **zadx-appsec-engineer** — Application security engineer. Use for secure code review, OWASP Top 10, and dependency audits.
- **zadx-penetration-tester** — Penetration tester (authorised, Zad X systems only). Use for attack-surface testing on Zad X staging.
- **zadx-privacy-compliance** — Privacy and child-safety compliance officer. Use for COPPA, GDPR-K, app-store kids' policies, and the privacy policy.
- **zadx-cloud-security** — Cloud and infrastructure security engineer. Use for IAM, secrets, network, backups, and WAF.
- **zadx-incident-response** — Incident response lead. Use for breach playbooks, monitoring alerts, and post-mortems.

## Quality
- **zadx-qa-lead** — QA lead. Use for test strategy, test plans, and release readiness.
- **zadx-test-automation** — Test automation engineer. Use to write and maintain automated tests.
- **zadx-exploratory-tester** — Manual and exploratory tester. Use to break things the way a curious 7-year-old would.
- **zadx-bug-fixer** — Bug fixer. Use to triage and fix bugs from qa/bugs.

## Marketing
- **zadx-marketing-director** — Digital marketing director. Use for go-to-market strategy, positioning, and launch plans.
- **zadx-seo-specialist** — SEO specialist. Use for keywords, metadata, schema, and site structure.
- **zadx-aso-specialist** — App Store Optimisation specialist. Use for store listings, screenshots, and keywords.
- **zadx-content-social** — Content and social media manager. Use for posts, calendars, and video ideas.
- **zadx-email-marketing** — Email and CRM marketer. Use for the waitlist, onboarding emails, and newsletters.
- **zadx-growth-analyst** — Growth and analytics analyst. Use for KPIs, funnels, and privacy-safe analytics.

## Skills Addons
- **zadx-tooling-lead** — Lead of the Skills & Add-ons team. Use to manage which skills, plugins, connectors, and libraries the team uses.
- **zadx-skills-curator** — Skills curator. Use to create, test, and improve the team's Claude skills.
- **zadx-integrations-manager** — Integrations and connectors manager. Use for Gmail, GitHub, analytics, and payment integrations.

## Reporting
- **zadx-daily-reporter** — Daily reporter. Use at the end of each cycle to write and email the daily summary to the owner.
- **zadx-build-device-test-engineer** — Build & device test engineer (GitHub Actions, Android emulator, Firebase Test Lab real phones, iOS/Windows/backend builds)
